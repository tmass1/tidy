Setup guide

Tidy walks you through all of this the first time it opens. It takes a few minutes, and you need an Apple Silicon Mac with macOS 14 Sonoma or later.

Last updated 6 November 2026

Set it up once

  1. Install Tidy

    Download Tidy, open the zip, move Tidy to your Applications folder and open it. Tidy lives in the menu bar, so it won’t appear in the Dock.

  2. Add your Anthropic API key

    Create a key at console.anthropic.com and paste it into Tidy, which checks that it works. Using the API is billed by Anthropic and is separate from a Claude subscription, so your account needs API credits. The key stays in your Keychain.

  3. Allow Accessibility

    Tidy presses ⌘C to read what you selected and ⌘V to put the new version back, and macOS asks you to allow that once. Choose Open System Settings… and turn Tidy on. Tidy moves on by itself when it’s allowed.

  4. Check your shortcut

    The shortcut is ⌥⌘C. If you’d prefer a different one, record it here or later in Settings.

  5. Try it on a draft

    Tidy gives you a sample message that’s already selected. Press your shortcut and watch it clean up.

To go through these steps again, open Settings from the menu bar icon and choose Run setup under General.

Clean up a message

  1. Select your draft in any app and press ⌥⌘C.
  2. Read the new version. Changes shows what’s different, and holding Original shows your draft.
  3. Pick a different mode or type a change in your own words, if you want one.
  4. Press ⌘↩ to put it back over your selection, or Esc to leave your draft alone.

If something’s not right

Nothing happens when you press the shortcut

Another app may be using it. Open Settings, and under General, look for Another app already uses that shortcut. If it’s there, pick a different one.

Tidy asks you to turn it on in System Settings

Go to System Settings › Privacy & Security › Accessibility and turn Tidy on. If it’s already on and Tidy still asks, turn it off and on again. You can paste text into the panel in the meantime.

The panel opens empty

Tidy didn’t find any selected text. Select your draft and try again, or paste it into the panel. When Tidy didn’t read your selection, the button pastes the result into your app instead of replacing the selection. Choosing Clean Up Clipboard from the menu bar icon works on what you’ve already copied.

Your API key was rejected

The key may be mistyped, or it may have been deleted. Create a new one at console.anthropic.com and paste it into Settings (⌘,).

This API key doesn’t have access to that model, or Model not found

Choose a different writing model in Settings, under General.

Rate limited, or Claude is overloaded right now

Wait a moment and press ⌘R to try again.

A message about your credit balance

Your Anthropic account needs more API credits. You can add them at console.anthropic.com. A Claude subscription doesn’t cover API use.

Tidy copies or pastes the wrong thing on your keyboard

Tidy presses the physical C and V keys, which can go wrong on keyboard layouts other than QWERTY. This is a known limitation.

Removing Tidy

If you turned on Open Tidy at login, turn that off in Settings. Then choose Quit Tidy from the menu bar icon and drag Tidy from Applications to the Trash. In System Settings › Privacy & Security › Accessibility, you can remove Tidy from the list too.

To also remove your history, modes, settings and API key from your Mac, paste this into Terminal and press Return:

rm -rf ~/Library/Application\ Support/Tidy
defaults delete com.tommymassaro.tidy
security delete-generic-password -s com.tommymassaro.tidy

This deletes them for good. Your key still works at Anthropic until you delete it at console.anthropic.com.
