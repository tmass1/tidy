# Tidy iPhone Implementation Plan

> Execute inline with executing-plans; use a fresh final reviewer.

**Goal:** Native text → mode → streaming rewrite → Original/Changes/Final → Copy/Share.
**Architecture:** Shared TidyCore package, SwiftUI app, Share extension, shared local preferences and Keychain.
**Tech Stack:** Swift 5 mode, SwiftUI/UIKit, URLSession, XCTest, XcodeGen (installed tooling only).
**Spec:** ../../ios/AUDIT.md

## Constraints
Preserve prompts, provider IDs, mode instructions and Mac storage. No embedded secrets, no second backend/account, no Figma, no Mac install/deploy. User requested reasonable defaults and immediate prototype implementation; use native execution without another design gate. Work in the isolated worktree.

## Tasks
- [x] Extract models, prompts, streaming client and diff into Sources/TidyCore; wire Mac dependency. Add Tests/TidyCoreTests regression coverage. Verify swift test and swift build.
- [x] Add shared RewriteSession with cancellation generation guard, empty/oversized input, explicit completed/error/cancel states and exact request retry. Add failing tests for completion and stale-output handling, then implement and run suite.
- [x] Add iOS/MobileShared store, Keychain wrapper, Lens tokens and editor; app settings/mode import and extension input loading. XcodeGen spec with matching entitlements and extension-safe build setting. Add deterministic DEBUG sample transport; never read a real key for preview.
- [x] Build and run app and extension in Simulator; exercise share sheet entry, reviews, copy/share, cancel/retry, missing key, mode persistence, dark and accessibility sizing. Capture screenshots and preserve reproducible instructions.
- [x] Fresh review, resolve material findings, rerun affected tests, document real vs fixture verification and device/live-API limitations.

## Review focus
Partial/truncated streams must not appear complete; cancelled streams must not overwrite new requests; key sharing must not fall back to insecure storage; malformed input/imports must fail visibly; preview must not impersonate live generation; edits must invalidate previous results; extension must complete/cancel its context.
